# VideoEdit
Video Editor - Rotate, Scale, Audio Editor
This software allows you to edit your video files by applying various customizable features. With a simple and intuitive graphical user interface (GUI), users can rotate, resize, and remove audio from their video files. Here’s a breakdown of the key features:

Features:
Browse and Select Video Files:

Easily choose a video file from your local PC using the "Browse" button.

Audio Options:

Keep Audio: By default, the software retains the original audio of your video. If you prefer to remove the audio, simply uncheck the "Keep Audio" checkbox.

Rotation Options:

Apply Rotation: You can rotate your video in 90° counter-clockwise (left) or 90° clockwise (right).

Rotation can be applied only if selected. If you don’t want to rotate your video, just leave this option unchecked.

Resize Video:

You can resize the width of the video while maintaining the original aspect ratio.

Enter the new width in pixels, and the software will automatically adjust the height based on the original aspect ratio.

Save and Export Video:

After applying the selected options, the software will create and save a new version of the video with the modifications.

The edited video will be saved with the suffix “_edited” appended to the original file name.

How to Use:
Step 1: Click the "Browse" button to select a video file from your PC.

Step 2: Choose whether you want to keep or remove the audio by checking or unchecking the "Keep Audio" box.

Step 3: If you want to rotate the video, check the "Apply Rotation" box and choose the direction of rotation (Left or Right).

Step 4: If you need to resize the video, check the "Resize Width" box and enter the new width (keeping the aspect ratio intact).

Step 5: Click "Process Video" to apply the changes and save the edited video file.

Supported Video Formats:
This software supports a wide range of popular video formats, including:

MP4

AVI

MOV

MKV

FLV

WMV

This tool is great for anyone who needs a quick and simple way to edit video files by rotating them, resizing them, or removing audio without the need for advanced video editing software.
